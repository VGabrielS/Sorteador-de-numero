# Sorteador de Números 🚀

Ferramenta online para sortear números aleatórios dentro de um intervalo definido pelo usuário.

## ✨ Funcionalidades
- Definir a quantidade de números a sortear, e o intervalo mínimo e máximo
- Opção de "Não repetir número", evitando duplicatas no resultado
- Exibir o resultado do sorteio em lista, com opção de sortear novamente

## 🔧 Tecnologias utilizadas
- HTML5
- CSS
- JavaScript (vanilla, sem frameworks nem build)

## 📁 Estrutura do projeto

```
index.html      Estrutura da página (formulário de sorteio e resultado)
styles.css      Estilos da aplicação
scripts.js      Lógica de geração dos números aleatórios
img/            Logo e elementos gráficos
Icon/           Ícones usados na interface
```

## ▶️ Como executar

Por ser um projeto estático (sem build), basta abrir o `index.html` diretamente no navegador ou servir a pasta com qualquer servidor local, por exemplo:

```bash
npx serve .
```

ou, usando a extensão **Live Server** do VS Code, clicando com o botão direito em `index.html` → "Open with Live Server".
